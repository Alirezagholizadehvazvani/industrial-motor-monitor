# docs

| File | What it is |
|---|---|
| `hardware.md` | Hardware, pin map, sensing chains and bill of materials |
| `assembly-notes.md` | Build order, problems and recorded bench observations |
| `safety.md` | Status, hazards, rules and open items |
| `requirements-specification.pdf` | Requirements, status of each requirement and risk register |
| `challenges/` | Problems met during the build and what was learned |
| `schematics/` | Drawings made for this project. They are illustrations, not company documents |
| `Pump_Protection_*.pdf` | Early planning and progress documents from the start of the project. They record earlier values (for example a 32 A limit, a 180-250 V window and a 4 s startup delay) that the current firmware does not use. The source code and `safety.md` hold the current values |
